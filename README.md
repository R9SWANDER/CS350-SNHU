# CS350-SNHU
The following submissions were from CS-350, and implemented various embedded device functions, with a raspberry pi asthe controller. 

The module 5 milestone implemented a state machine, which would transfer messages from written word to morse code, and then display the messages in morse code using different colored LED's and pulse lengths. I am happy with this project as the system could be easily extended to tramsit and receive messages through morse code over the web, and the project was the first where I learned a lot about troubleshooting state machines. 

The Thermostat, or final project, implemented a temperature sensor, and the goal was to create a state machine which would react to the ambient temperature and either 'cool' or 'heat' a room based on the current state, or mode, it was in. I particularly enjoyed this project because it felt like a system which could realistically be implemented out in the world today to implement an actual thermostat. 

The skills I learned in this class will be very transferrable to others. This class taught me how to remote access systems, how harware wiring works, how state machines work and why they are useful, and how to create an embedded system.
